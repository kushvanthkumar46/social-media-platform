# Social Media App

This project is a static frontend app that can be hosted on Vercel or any simple web host.

## Open locally
Open the folder in a browser directly or use a simple static server.

## Deploy to Vercel
1. Push this project to GitHub.
2. Import the repository in [Vercel](https://vercel.com/new).
3. Keep the project root as the Root Directory and use the default settings.
4. Click **Deploy**. The included `vercel.json` routes the app pages and assets correctly.

You can also deploy from the project folder with the Vercel CLI:

```bash
npx vercel
```
